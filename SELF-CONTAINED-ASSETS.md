# Self-contained image assets

This export includes every image used by the PD Hub.

- `public/uh-updated-seal.svg` supplies the color-adjustable campus seal artwork used on event cards.
- `public/system-seal.jpg` supplies the UH System seal used in the site header. It was copied from the University of Hawaiʻi website at https://www.hawaii.edu/wp/wp-content/uploads/2015/12/system-seal.jpg on September 2, 2026.

The exported source references the local `/system-seal.jpg` file, so the site no longer requires an external image request to display the header seal.
